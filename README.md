## Featured Projects

### 🔍 EvalRAG : RAG Pipeline + Evaluation Framework
A production RAG system paired with an evaluation harness I built from scratch to catch quality regressions before they ship.
- Hybrid retrieval (BM25 + dense) with golden datasets and regression scoring for faithfulness and relevance.
- FastAPI backend, Qdrant vector store, React frontend.
- Grew out of production work that cut catalog processing time by 80% across 100,000+ documents.
- *Keywords:* `RAG` `LLM Evaluation` `FastAPI` `Qdrant` `Python`

### 🏷️ NER on Travel Orders
Automated extraction of structured entities (names, dates, expenses) from unstructured administrative documents.
- Fine-tuned CamemBERT/RoBERTa models for French administrative text.
- Handled low-resource data through custom augmentation to push F1 up without more labels.
- Integrated into a batch processing pipeline for real document ingestion.
- *Keywords:* `NLP` `Transformers` `Token Classification` `PyTorch`

### 🧾 AI E-Invoicing Platform
End-to-end OCR system that turns invoice PDFs into structured, validated financial data.
- Hybrid pipeline using LayoutLM for document parsing and field extraction.
- FastAPI backend and React frontend with a human-in-the-loop verification step.
- Fully containerized with Docker for production deployment.
- *Keywords:* `OCR` `Full-Stack AI` `FastAPI` `Computer Vision`

### 🚕 Reinforcement Learning: Taxi Driver
Comparative study of agent navigation efficiency in the OpenAI Gym environment.
- Evaluated Tabular Q-Learning vs. Deep Q-Networks (DQN) performance.
- Tuned epsilon decay and discount factors to optimize reward curves.
- *Keywords:* `Reinforcement Learning` `Deep Q-Learning` `OpenAI Gym`

### 🫁 Pneumonia Detection (Medical Imaging)
Binary CNN classifier for chest X-ray diagnosis with a focus on model interpretability.
- Transfer learning (ResNet/EfficientNet) to handle class imbalance.
- Grad-CAM visualizations for clinical explainability (XAI).
- *Keywords:* `CNN` `Transfer Learning` `Explainable AI (XAI)` `Keras`
